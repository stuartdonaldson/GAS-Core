GAS-Core: Static Frontend for Apps Script

Live demo companion to best-practices/gas-static-frontend — porting an Apps Script HtmlService page to a static page that calls the GAS web app as a plain JSON API. This page is itself the static half of that pattern: a top-level document, hosted on GitHub Pages, with no server behind it except whatever GAS backend you point it at below.

1. Point this page at a GAS backend

Deploy gas-backend-example.js + appsscript.json.example from the same folder as a GAS web app (clasp deploy, access ANYONE_ANONYMOUS), then paste its /exec URL here. Stored only in this browser's localStorage — never sent anywhere but the URL you provide.

2. Sign in with Google (identity check)

Uses only the non-sensitive openid/email/profile scopes — no consent screen, no access to your Drive/Gmail/Calendar. See the README's "identity & access control" section for why this doesn't require Google app verification. Requires a GIS OAuth client ID with this page's origin registered as an authorized JavaScript origin.

Reference implementation only — no data leaves your browser except calls you explicitly make to the backend URL you configure above. Source: static/ · best-practices/gas-static-frontend
